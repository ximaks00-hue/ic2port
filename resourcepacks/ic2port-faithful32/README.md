# IC2 Port Faithful 32x (Optional Companion Pack)

This pack is intentionally separate from the base mod JAR.

## Goal

Provide the closest IC2 Classic look for players who want Faithful 32x style.

## Legal model

- Base mod (`ic2port`) ships Tier Green assets only.
- This companion pack is where conditional Tier Yellow assets can be distributed,
  but only when explicit permission is available.

See:

- `LICENSE-ASSETS.md`
- `docs/ASSET_PERMISSION_REQUESTS.md`

## Install

1. Build or collect approved textures into this pack under `assets/ic2port/textures`.
2. Zip the `ic2port-faithful32` folder contents.
3. Put zip in `.minecraft/resourcepacks`.
4. Enable it above the main IC2 Port assets in Minecraft resource packs UI.
