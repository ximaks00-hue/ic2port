# Asset Permission Request Templates

Use these templates when requesting redistribution permission for IC2-like
textures that are not clearly licensed for bundling in IC2 Port.

## 1) Request to CrossVas (F32AddonsIC2Classic)

Subject: Permission request to redistribute selected F32AddonsIC2Classic textures in IC2 Port

Hello CrossVas,

I maintain the IC2 Port mod project. We are trying to keep visual parity with
IC2 Classic while publishing legally on CurseForge/Modrinth.

Your pack `F32AddonsIC2Classic` is currently our best visual match for several
textures (for example: steam fluid, hazmat set, and capacitor cell icon).

Could you grant us permission to redistribute selected textures from your
repository inside the IC2 Port mod JAR?

If yes, please confirm:

1. Whether redistribution in CurseForge/Modrinth releases is allowed.
2. Required attribution text (name, link, license text, credits wording).
3. Whether edits/resizing/recoloring are allowed.
4. Any restrictions we must follow.

If you prefer, we can distribute this as a separate optional resource pack
instead of bundling in the base mod.

Thank you for your work and for considering this request.

Best regards,
IC2 Port maintainers

## 2) Request to Speiger (IC2 Classic)

Subject: IC2 Port request for texture reuse permission / sublicense terms

Hello Speiger,

I maintain the IC2 Port mod project. We are working on visual parity with
IC2 Classic while respecting licensing boundaries.

Could you clarify whether selected IC2 Classic textures may be reused in IC2
Port releases, and under what conditions?

If allowed, please share:

1. Scope of permitted assets (specific folders/items/blocks).
2. Allowed distribution channels (CurseForge/Modrinth/GitHub).
3. Required attribution and links.
4. Whether modifications are allowed (resolution changes, recolors, edits).
5. Any restrictions for commercial/non-commercial publication.

If direct reuse is not allowed, we will keep IC2 Classic assets as reference
only and continue with independently sourced textures.

Thank you for your time.

Best regards,
IC2 Port maintainers
