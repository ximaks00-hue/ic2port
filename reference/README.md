# IC2 Reference Material

This folder contains reference artifacts for comparing IC2 Port against the original **Industrial Craft 2** mod.

## Important note on source code

The official IC2 Java Edition **source code is not open source**. The [IndustrialCraftMC/IndustrialCraft2](https://github.com/IndustrialCraftMC/IndustrialCraft2) repository is a community feedback tracker, not a source dump.

## What is included

| Path | Description |
|------|-------------|
| `ic2-classic/` | Clone of [TinyModularThings/IC2Classic](https://github.com/TinyModularThings/IC2Classic) (bugtracker + API notes) |
| `ic2-official/` | Links and metadata for official IC2 builds |
| `ic2/jars/` | Downloaded IC2 dev/API JARs from the official Maven (local only, gitignored) |

## EU (Energy Unit) tier reference (IC2)

| Tier | Name | Max packet size |
|------|------|-----------------|
| 1 | LV | 32 EU/t |
| 2 | MV | 128 EU/t |
| 3 | HV | 512 EU/t |
| 4 | EV | 2048 EU/t |

## IC2Classic

IC2Classic is a community fork maintained by Speiger. Its GitHub repo contains API documentation for newer versions and serves as a structural reference for energy tiers, machines and progression — even though it is a separate codebase from IC2 Experimental.
